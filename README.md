# tayllatheodoro.github.io

Personal site, built by GitHub Pages with Jekyll from `main`.

- `index.md`: the bio text and page structure.
- `_data/research.yml`: research highlights (title, authors, venue, links, summary, optional thumbnail).
- `_data/publications.yml`: the full publication list.
- `_layouts/default.html`: header, nav, footer.
- `assets/css/style.css`: styling (light and dark mode).
- `cv.pdf`: compiled from the [tayllatheodoro](https://github.com/tayllatheodoro/tayllatheodoro) LaTeX repo. Replace when the CV changes.
- `photo.jpg`: add a square headshot with this name to show it in the header.
- `img/`: optional thumbnails referenced from `research.yml`.

Local preview: `bundle exec jekyll serve` with the `github-pages` gem, or just push and wait a minute.
