# tayllatheodoro.github.io

Personal site, served by GitHub Pages from `main`.

- `index.html` and `style.css`: the whole site. No build step.
- `cv.pdf`: compiled from the [tayllatheodoro](https://github.com/tayllatheodoro/tayllatheodoro) LaTeX repo. Replace when the CV changes.
- `photo.jpg`: add a square headshot with this name to show it in the header.
- `img/*.png`: optional thumbnails for the research highlights (dynatrack, dynacell, dynaclr, meso-regions, mise). Text placeholders show until they exist.
